# 我的桌面（MyLauncher）

精簡的 Android 啟動器：主畫面＋**完全自訂的左滑頁**（沒有 Google 資訊流）。

## 功能
- **左滑頁**：自由加入 Android 小工具（行事曆、天氣、記事、任何 App 的 widget）、App 捷徑組、便條；可排序、調高度、刪除
- **主畫面**：時鐘日期＋常用 App
- **App 抽屜**：往上滑或按「所有應用程式」，可搜尋；長按 App → 加到主畫面／左滑頁、資訊、解除安裝
- 長按主畫面空白處：換桌布、系統設定

## 取得 APK（GitHub 自動編譯）
1. 在 GitHub 建一個新的 **Private** repository
2. 把這個資料夾裡的所有檔案上傳（含 `.github` 資料夾）
3. 到 repository 的 **Actions** 分頁，等「Build APK」跑完（約 3–5 分鐘）
4. 點進那次執行，下方 **Artifacts** 下載 `MyLauncher-apk`（zip 內就是 APK）

或用電腦的 Android Studio 開啟此資料夾 → Build → Build APK(s)。

## 安裝與設為預設桌面
1. 手機安裝 APK（需允許「安裝未知應用程式」）
2. 設定 → 應用程式 → 預設應用程式 → 主畫面應用程式 → 選「我的桌面」
3. 想換回原本的桌面，同一個地方改回即可

## 第一次加小工具
左滑頁「＋ 新增項目」→「Android 小工具」→ 選一個 → 系統會詢問是否允許「我的桌面」建立小工具，按允許（勾選「一律允許」之後就不會再問）。

固定簽章檔 `app/debug.keystore` 讓每次更新都能直接覆蓋安裝、設定不會消失。
